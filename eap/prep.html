课前口语训练清单（做什么）

  • 每日 10–15 分钟限时口语：随机抽论题（教育 / 科技 / 文化 / 多语身份），30 秒倒计时先逼出 1 个立场，再用 1 分钟补 2–3 个角度论据。
  • 建立"论据素材库"：按课程主题（语言学习、身份认同、EMI/英语授课环境）预存 3–5 个可用例子与视角，降低现场编造压力。
  • 英语自言自语 / 录音回听，练"想到就能说"的流利度；对照雅思口语 6.5–7 标准校准。
  • 找同伴 / 学习小组做 2 分钟英文 mini-presentation 并互给反馈（呼应大纲"rehearse presentations"建议）。
  • 预热课程主题（Jay Walker TED、Lin 2010 English and Me、Galloway 2017 EMI），先想好你对"多语身份 / 语言学习挑战"的立场。
💡 词汇无需大规模扩充：高考–四级区间已足以应对课程。针对性补学术写作高频搭配（They Say / I Say 模板句、academic chunks）比背单词性价比更高。
📚 两本书与口语的关系：Keys for Writers 第 24 章 "Oral and Multimedia Presentations" 是专门的口语/演讲章节，可直接照练；其 Part IX（多语写作者语法）也能提升口语准确度。They Say / I Say 本身无口语章节（纯写作书），但它的模板句（"On the one hand… on the other hand… my own view is…""I disagree because…"）正是学术对话的话术骨架——把它们当"口头句型"朗读+即兴填空，正好练 30 秒观点+多论据。

1提前了解大纲 / 先修知识 / 考核方式

  • 通读 Syllabus 全文，重点标记：课程目标、每周 schedule、评分政策、AI 政策、迟交政策。
  • 确认先修要求：大纲明确写"无先修课程（No prerequisite courses required）"——但仍需自查下列能力基线。
  • 对照"课程学习成果"自查先修能力缺口：
    • 能否较流畅阅读英文学术文本并提炼论点；
    • 能否用英语写 summary 与 response（引用 / 转述 / 注明出处）；
    • 能否用英语写"立场清晰 + 论据支撑 + 例子"的短文；
    • 能否在课堂 / 小组中用英语参与讨论。
  • 熟记四项考核板块与权重（见第 4 部分），建立"分数地图"。
  • 记录关键节点：开课 8/24、SW1 截止 9/7（据 schedule），以及各 draft / final 截止日。
  • 熟悉 DKU 成绩量表：A 93–97、A- 90–92、B+ 87–89、B 83–86…（目标锁定 A / A-）。

2针对薄弱环节补充基础学习资源

  • 采购 / 借阅两本指定教材，开课前到手：They Say / I Say (6th) 与 Keys for Writers (9th)。
  • 学术阅读偏弱 → 预习 They Say / I Say 第 1–2 章"他人说 / 我说"框架，练 skim + 抓主旨。
  • 学术写作 / summary 偏弱 → 用 Keys for Writers 熟悉引用、paraphrase、避免 plagiarism 规范。
  • 英语表达 / 语法准确性偏弱 → 注册 WLS（Writing and Language Studio）账号，了解可预约服务（论文、语言点、口语练习、演讲彩排、阅读策略）。
  • 口语 / 课堂讨论偏弱 → 找同伴做英文主题对谈；预热课程将用到的 Jay Walker TED、Lin (2010) English and Me 等材料。
  • 浏览 LCC Writing and Language Studio 网站，收藏常用资源页备用。

3建立课前预习与笔记习惯

  • 开课前熟悉 Canvas 课程站结构（每周一个 section，含学习材料与任务），建立"每周清单"跟踪。
  • 采用大纲明确建议的主动阅读法：读前看问题 → 读中标记主旨与视角 → 读后记录疑问 → 准备课堂 / 论坛发言。
  • 固定一套阅读笔记模板：每篇记"核心论点 / 作者视角 / 我的疑问 / 可引用句"。
  • 建立写作流程习惯（大纲建议）：thinking → pre-writing → drafting → 获取反馈 → revising → editing，提前演练。
  • 养成"每日查 Canvas + 邮箱"习惯，避免错过公告与截止。
  • 为每次作业预留"反思 cover sheet"草稿栏，记录写作过程与课堂反思。

5规划时间管理与沟通渠道

时间管理（做什么）

  • 按"10 小时 / 周 异步投入"预留固定时段（如每周 2–3 个固定 block 做阅读 + 写作）。
  • 以 Canvas 每周 section 为节奏单位，按"布置顺序"按时完成任务，不积压。
  • 为每次写作任务预留完整流程时间（构思 → 草稿 → 反馈 → 修订 → 编辑），避免压线提交。
  • 用日历标注所有 due date 与 draft 节点，自设提前 1–2 天的个人截止线。

沟通渠道（做什么）

  • 入微信群（码 0001）；课程问题发群而非私信教师。
  • 预约并完成教师 office hour ≥3 次（大纲硬性建议，影响 Engagement 分）。
  • 注册并预约 WLS 教练，就论文 / 语言点 / 口语 / 演讲彩排获取反馈（需邮件向教师提交报告）。
  • 组建 3–4 人学习小组，定期讨论阅读与 topics、互相激励、演练口语。
  • 善用 DKU 邮箱与 Canvas 消息；教师周一至五 24h 内回复，周末回复慢。
  • 联系往届学生：通过 DKU 学生社群 / 同乡会 / 课程群了解真实经验与评分偏好。注
  • 遇技术 / 特殊情况：IT 支持 400-816-7100；紧急情况提前联系教师。
📌 关于"助教"：本版 Syllabus 未列明 TA；主沟通渠道为教师 office hour + WLS 教练。入学后可在 Canvas / 微信群确认是否有 TA，并以教师公布为准。
